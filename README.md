## ✨ Features

- 🎨 Modern gradient design with smooth animations
- 🌙 Dark mode with localStorage persistence
- 📱 Fully responsive (mobile, tablet, desktop)
- 👤 Individual profile pages for each team member
- 🔍 SEO optimized with meta tags
- 📬 Netlify Forms powered contact form
- ⚡ Fast loading (no framework, pure HTML/CSS/JS)
- 🚀 Automated CI/CD with GitHub Actions + Netlify

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Font Awesome 6, Google Fonts (Inter)
- Netlify (hosting), GitHub Actions (CI/CD)
